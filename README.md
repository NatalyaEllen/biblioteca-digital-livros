# Biblioteca Digital de Livros

Projeto desenvolvido em Laravel para a disciplina de fullstack no curso de Engenharia de Software.

## Descrição

A Biblioteca Digital de Livros é uma aplicação web que permite aos usuários autenticados pesquisar livros por meio da API pública Open Library e salvar suas obras favoritas em uma coleção pessoal.

## Tecnologias utilizadas

- PHP
- Laravel
- MySQL
- Laragon
- DBeaver
- Thunder Client
- Git
- GitHub
- Open Library API

## Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Pesquisa de livros em API externa
- Exibição de título, autor, ano de publicação e capa
- Salvamento de livros favoritos
- Listagem de favoritos
- Remoção de livros favoritos
